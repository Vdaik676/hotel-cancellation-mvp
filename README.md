## Быстрый запуск Windows

1. Распакуйте ZIP целиком в обычную папку. Не запускайте из окна архива.
2. Нужен Python **3.12 x64**. Установщик ищет его через `py`, в стандартной пользовательской папке и, если доступна, в локальной среде Codex. Python 3.13 через `py` сам по себе не заменяет 3.12. Для своего пути можно задать переменную `MVP_PYTHON` с полным путём к `python.exe` версии 3.12.
3. Запустите `setup_windows.bat`: создаётся `.venv`, ставятся версии из lock-файла и проверяется загрузка модели. Интернет нужен только при первой установке. Успешное завершение — сообщение `Setup completed`.
4. Запустите `start_demo.bat` и откройте **http://127.0.0.1:8501**. Остановка — Ctrl+C в окне сервера.

Команды вручную, из корня проекта:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```

macOS/Linux: `python3.12 -m venv .venv`, затем `.venv/bin/python -m pip install -r requirements-lock.txt` и `.venv/bin/python -m streamlit run streamlit_app.py`.

## Проверка работы

Выберите «Пример 2», нажмите «Заполнить пример» и «Оценить риск». Ожидаемый результат — 27,7%, средний риск. При нулевом числе всех гостей должна появиться ошибка, а предыдущий результат — исчезнуть.

## Воспроизведение

В командах ниже используйте Python из созданной `.venv`:

```text
python -m pytest -q
python evaluate.py --output reports/evaluation_repeat_new.json
python -m src.train
```

`src.train` заново обучит все три модели, выберет по validation и **перезапишет** artifacts и метрики. Для демонстрации и обычной проверки запускайте только приложение или evaluate. Исходный `data/hotels.csv` проверяется по SHA-256. Исходный URL и атрибуция — `data/source.json` и `data/ATTRIBUTION.md`.

## Результат и границы

Фактические AUC/F1/recall и недостигнутые цели показаны в интерфейсе и `reports/metrics.json`. Целевые AUC 0,80 и F1 0,70 не достигнуты; они не отменены. Recall ≥ 0,70 выполнен. Исходные требования и крайний срок проекта 14.11.2026 сохраняются. Это учебный MVP без PMS/CRM и промышленного пилота.

## Устранение проблем

- «No module named …»: зависимости ставились не в тот Python. Выполните установку через `.venv\Scripts\python.exe`.
- Ошибка версий model.joblib: используйте lock-файл и Python 3.12; не заменяйте scikit-learn произвольно.
- Нет модели: распакуйте комплект целиком, проверьте `artifacts/model.joblib`.
- Порт занят: закройте старый сервер или добавьте `--server.port 8502` и откройте соответствующий адрес.
- Если отсутствует Python 3.12, установите официальный Python и затем повторите setup. Установка Python не входит в батник.

Сохранённые Joblib-файлы — только из этого собственного комплекта; не подменяйте их произвольными файлами из интернета.
