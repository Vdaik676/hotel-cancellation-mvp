# Инструкция менеджера бронирований

Версия 1.2 · Актуально 06.11.2026 · Ответственный: Арсений · Для пользователя.

Инструмент помогает выбрать брони, которые стоит просмотреть вручную. Для работы нужны только параметры брони; имена, телефоны и номера документов не вводятся.

1. Откройте вкладку «Оценить бронирование».
2. Укажите тип отеля, месяц заезда, питание, сегмент и забронированный тип номера. Расшифровки есть в блоке «Подсказки к полям бронирования». Буквы номера условные; они не соответствуют гарантированно классам отелей.
3. Введите дни до заезда, число ночей в будни и выходные, число взрослых, детей и младенцев. Должна быть хотя бы одна ночь и один гость.
4. Нажмите «Оценить риск». При ошибке исправьте указанное поле и отправьте форму снова.
5. Используйте результат, чтобы определить порядок проверки броней: низкий риск — обычное наблюдение, средний — возможная проверка, высокий — приоритет для ручного просмотра. При необходимости сохраните JSON.

Процент — оценка модели, а не гарантия отмены. Нельзя автоматически отменять бронь, менять условия или связываться с клиентом только по этой оценке. Сценарий учебный, результат проверялся на исторических данных. При проблемах сообщите Арсению через командный чат, приложив шаги и текст ошибки без персональных данных.

## История проверок
Перед расчётом включите «Сохранить результат в локальную историю». Откройте вкладку «История проверок»: там время UTC, вероятность, категория риска, модель и порог. Сохраняются только успешные расчёты с включённой отметкой. Параметров и идентификаторов брони в истории нет. История сохраняется после перезапуска, доступна пользователям этой копии на ПК и ограничена 500 записями. Для очистки поставьте отметку подтверждения и нажмите «Очистить историю».
