# Быстрый запуск MVP

Версия 1.2 · Актуально 06.11.2026 · Ответственный: Арсений · Для проверяющего и нового участника.

1. Распакуйте весь ZIP в обычную папку, не запускайте файлы из окна архива.
2. На Windows нужен Python 3.12 x64. Запустите `setup_windows.bat` один раз. Дождитесь `Setup completed`. Интернет нужен для установки зависимостей. На другом ПК наличие Python проверьте заранее.
3. Запустите `start_demo.bat` и оставьте окно открытым. В браузере откройте http://127.0.0.1:8501.
4. Выберите «Пример 2», нажмите «Заполнить пример», затем «Оценить риск». Ожидаемый вывод: **27,7%, средний риск**.
5. Поставьте число всех гостей в 0 и снова отправьте форму. Ожидается сообщение о допустимом числе гостей; предыдущий результат исчезает.

На уже настроенном компьютере начинайте с шага 3. Для остановки нажмите Ctrl+C в окне сервера. Повторное обучение и скачивание CSV для демонстрации не нужны.

Если результат отличается или запуска нет, сохраните сообщение из консоли и откройте [Runbook](03_Runbook.md).
