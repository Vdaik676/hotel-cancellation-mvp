# Эксплуатационная инструкция

Версия 1.2 · Актуально 06.11.2026 · Ответственный: Арсений · Для запуска и устранения ошибок.

**Как устроен запуск.** Один локальный процесс Streamlit, localhost:8501. Python 3.12 x64 и зависимости из requirements-lock.txt. Отдельных учётных записей, сервера БД, ключей, интеграций и удалённого мониторинга нет. При запуске приложение загружает модель и схему входных данных из artifacts/. Не выставляйте учебный сервер в интернет.

**Проверка после установки.** Из корня папки:
```powershell
.\.venv\Scripts\python.exe ops_check.py
.\.venv\Scripts\python.exe -m pytest -q
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8501/_stcore/health
```
Первые две команды проверяют результат модели и сценарии, последняя — доступность запущенного процесса. После health откройте форму и прогоните пример 2. Для отчёта используйте `ops_check.py --json reports/local_check.json`. Это локальная проверка, не непрерывный мониторинг. Консоль запуска содержит сообщения процесса; входы пользователя приложением не записываются в журнал. Сохранённые JSON находятся у пользователя.

| Симптом | Действие | Кому передать |
|---|---|---|
| Python не найден | Установить 3.12 x64; проверить py -0p. При нестандартном пути задать MVP_PYTHON | Арсений |
| Порт 8501 занят | Остановить свой старый сервер Ctrl+C или запустить `.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py --server.port 8502` и открыть http://127.0.0.1:8502 | Арсений |
| Модель не загрузилась | Сверить архив, восстановить artifacts/ и requirements-lock.txt той же версии; повторить setup и ops_check | Вадим, Саид |
| Примеры недоступны | Форма остаётся доступной вручную. Восстановить demo/examples.json из ZIP | Арсений |
| Метрики или прогноз отличаются | Сохранить версию, ожидаемый и фактический вывод, шаги; воспроизвести на примере | Вадим, Саид |

**Обновление и откат.** Хранить неизменённый ZIP предыдущей версии. Новую версию распаковать отдельно, установить зависимости, проверить контрольные суммы и выполнить ops_check. При сбое остановить новую версию, запустить прежнюю из её папки, повторить пример 2 и зафиксировать откат. Не смешивать модель, схему и отчёты разных версий.

**К кому обратиться.** Если блокируется демонстрация или повреждена модель, сразу сообщить Саиду в командном чате; Арсений воспроизводит сбой, Вадим сверяет данные и модель. Канал для внешней эксплуатации и SLA учебной версией не предусмотрены.

## Локальная история
Файл `runtime/risk_history.sqlite3` создаётся при первом сохранении. Нужен доступ на запись в папку приложения. При недоступной или повреждённой базе результат прогноза всё равно выдаётся; отключите запись и сообщите Арсению. Для восстановления после повреждения остановите процесс и переместите файл в отдельную папку; при следующем сохранении появится новая база. Не включайте локальную историю в ZIP передачи или логи поддержки. Для проверки AT-05: `python benchmark_acceptance.py`.
