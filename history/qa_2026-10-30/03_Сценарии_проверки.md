# Сценарии проверки MVP

Дата: 30.10.2026. Общие условия: комплект «исправленный запуск», готовое окружение Python 3.12.14, модель из artifacts. Проверяем копию приложения. AppTest выполняет код интерфейса без обычного браузера; браузерные проверки перечислены отдельно.
