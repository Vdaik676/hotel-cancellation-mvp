# Карточка модели

Модель: E2_hist_gradient_boosting. Задача: бинарная классификация is_canceled=1. Для учебной демонстрации менеджеру бронирований, без автоматических решений.

## Обучение и выбор

11 признаков, train 51972 строк. Дубликаты удалены, одинаковые X сгруппированы в одну часть split. Выбор модели и порога на validation; test не используется для настройки. E2: 220 итераций, 15 листьев, lr=0.08, L2=2, seed=42.

## Фактическое качество test

ROC-AUC 0.730647; F1 0.537805; recall 0.735153; precision 0.423988; Brier 0.173678. Порог 0.294643. Матрица ошибок [[7725,4793],[1271,3528]]. AUC/F1 ниже целей ТЗ. Окончательная приёмка не подтверждена.

## Ограничения

- Только исторические данные 2015–2017 двух отелей; случайный grouped split, без временного пилота.
- После дедупликации состав и доля отмен изменились; метрики не относятся к исходной смеси записей.
- Признаки консервативно выбраны, но CSV не содержит историю на момент регистрации.
- Отдельная калибровка вероятностей не проведена; вероятности — оценки модели.
- Precision 42,4% при recall 73,5% означает много ложных тревог.
- Истинный эффект для отеля, качество по новым отелям и справедливость для групп не проверены.

Не использовать для отмены броней, цены или отказа гостям. Сначала аудит данных на дату прогноза и согласованный пилот.
